# Roadmap

The order matters.

## Stage 0 — Constitution

Status: STARTED.

Deliver:

- AGENT
- PRD
- context
- methodology
- sources
- validation
- architecture
- automation
- UI/UX
- decision log
- machine-readable config

Exit condition:
A fresh agent can explain the project without the original conversation.

## Stage 1 — Population Anchor

Deliver:

- official CPS ASEC acquisition;
- archive hashing;
- schema validation;
- weighted percentile;
- Bottom-10/20/30/50 research outputs;
- canonical Bottom-30 cutoff;
- tests;
- independent sanity checks.

Exit condition:
Two independent calculation paths reproduce the Bottom-30 cutoff within the expected percentile convention.

## Stage 2 — Observation Registry

Add a small set of official non-composite observations.

Start with the strongest, easiest-to-defend sources.

Do not chase completeness.

Exit condition:
Every observation has provenance, freshness and a deterministic ingestion path.

## Stage 3 — Prelaunch Site

Deliver:

- home;
- methodology;
- sources;
- history;
- prelaunch status;
- Bottom-30 cutoff;
- candidate observations;
- data-health state.

Exit condition:
A stranger can audit the main displayed values.

## Stage 4 — Composite Research

Deliver:

- normalization experiments;
- adequacy thresholds;
- correlation/double-counting review;
- sensitivity analysis;
- candidate pillar scores;
- methodology report.

Exit condition:
Composite behavior is stable enough to withstand hostile review.

## Stage 5 — Foundation 1.0

Requires explicit owner approval.

Deliver:

- methodology 1.0.0;
- official Foundation score if justified;
- historical baseline;
- revision policy;
- public reproducibility instructions.

## Stage 6 — Operations

Only after manual update process is trusted:

- agent-triggered one-command update;
- improved anomaly detection;
- optional scheduled checks;
- deployment verification.

## Deferred

- state/local indices;
- county/PUMA work;
- personal calculator;
- public API;
- newsletter;
- daily show tooling;
- predictive features;
- policy simulation;
- mobile app.

If a deferred feature threatens the current stage, say no.
