# Contributing

This project welcomes scrutiny more than agreement.

A useful contribution:

- identifies a wrong source interpretation;
- finds a reproducibility bug;
- provides a stronger primary source;
- demonstrates double counting;
- exposes sensitivity to a modeling choice;
- improves accessibility;
- adds a regression test;
- clarifies a limitation.

A weak contribution merely changes the index until it tells a preferred political story.

## Methodology changes

Open as a proposal first.

Include:

- current behavior;
- proposed behavior;
- rationale;
- evidence;
- expected historical impact;
- sensitivity analysis if relevant.

Methodology does not change through drive-by code refactors.
